📲 Enter the code in WhatsApp

  1. Open WhatsApp on the phone that has this number.
  2. Go to Settings, then Linked devices.
  3. Tap Link a device, then Link with phone number instead.
  4. Type the 8 character code. It expires quickly, so open WhatsApp first.
  5. Wait for the welcome message, then send .menu 🎉
The code is not accepted

Codes last about a minute. Tap Get pair code for a new one, then open WhatsApp → Linked devices → Link with phone number instead.

What is the free limit?

4 movies per day across all movie commands. It resets at 12:00 AM Sri Lanka time. Send .limit to see what is left.

What does Pro give me?

Unlimited movies. After you pair, the owner verifies your number and the bot starts working.

I linked it but the bot does not reply

Wait a few seconds and send .menu. On the Pro bot, replies start after the owner verifies you.

Is it safe to link my number?

Use a secondary number if you can. You can unlink any time from Linked devices in WhatsApp.
