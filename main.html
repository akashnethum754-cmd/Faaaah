Change anything with .set

Settings live in WhatsApp now. Send .set alone to see your current values, or change one or many at once.

.set BOT_NAME:My Movie Bot
✅ UPDATE SUCCESS 🎀 BOT_NAME ──❯ My Movie Bot
.set ANTI_DELETE:on, PREFIX:!
✅ UPDATE SUCCESS 🎀 ANTI_DELETE ──❯ true 🎀 PREFIX ──❯ !
  • BOT_NAMEName shown in menus
  • PREFIX1 to 3 characters
  • MODEpublic, private, inbox, groups
  • BOT_IMAGEImage link for replies
  • ANTI_DELETERecover deleted messages
  • BUTTON_MODETap buttons, not numbers
  • ALWAYS_ONLINEStay online
  • AUTO_TYPINGShow typing
  • STATUS_VIEWView statuses
  • AUTO_LIKELike statuses

Use on / off (or true / false) for switches. Changes apply to your running bot right away, and the bot re-checks its saved settings every 5 minutes.

Enter the code in WhatsApp

  1. Open WhatsApp on the phone that has this number.
  2. Go to Settings, then Linked devices.
  3. Tap Link a device, then Link with phone number instead.
  4. Type the 8 character code. It expires quickly, so open WhatsApp first.
  5. Wait for the welcome message, then send .menu.
